# 09: Apply through the agent

**What to build:** From a job the agent already found, a person can get the application questions, a guide filled from their CV, and have a message sent only after they say yes.

**Blocked by:** 08: find_jobs and get_startup

**Status:** ready-for-agent

- [ ] The agent can return the application questions for a found job
- [ ] The guide is filled from the person's CV, and anything the CV does not answer is asked rather than invented
- [ ] A message is sent only after the person says yes
- [ ] What was sent is recorded
- [ ] The hiring contact comes from a private contacts file that is never committed, published, or written into an issue or log
- [ ] The cap is 3 messages a day, email and LinkedIn together
