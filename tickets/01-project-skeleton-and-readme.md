# 01: Project skeleton and README

**What to build:** A person who opens the repo can read the README and understand the product: a public directory of startups that will employ someone remotely from Spain, how a company gets on the list, what pay means here, and what an agent will be able to do. The repo has the empty layout the rest of the work fills.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The README states the source of truth is the public directory of startups that will employ someone remotely from Spain
- [ ] The README states both gates: the company is a startup, and at least one open role is remote and employable from Spain
- [ ] The README names the eligibility classes `spain-named`, `eu-eea`, `worldwide`, and `contractor`, and states that a bare "Remote", a US-only line, a country list that omits Spain, and an on-site Spain office leave the company off the list
- [ ] The README states pay is only what a posting states, attached to the job, never a company median
- [ ] The README describes the published directory, the crawl of kept boards, and the agent surface: find roles, see why a startup is listed, apply only after a yes, at most 3 messages a day, with hiring contacts kept private
- [ ] The README describes the hand list, companies kept with `"via": "hand"`, and the strike-off (`"no"` for good, or a date to recheck)
- [ ] The README names where startups are found, in order: a hand list, then YC, then Common Crawl boards with a known headcount under a cap, then Wellfound
- [ ] The repo has a place for the ATS crawl, the published JSON, the MCP server, the agent skill, the landing page, and tests
